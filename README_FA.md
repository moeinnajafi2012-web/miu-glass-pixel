# MUI Glass Pixel Launcher

لانچر ساده و قابل توسعه با ظاهر الهام‌گرفته از Pixel و کارت‌های شیشه‌ای.

## ساخت APK با Android Studio

1. Android Studio را نصب و اجرا کنید.
2. گزینه **Open** را بزنید و پوشه پروژه را انتخاب کنید.
3. اجازه دهید Gradle Sync تمام شود. در SDK Manager، Android SDK Platform 36 را نصب کنید.
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیرید.
5. فایل APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
6. APK را به دستگاه اندرویدی منتقل و نصب کنید. سپس دکمه Home را بزنید و **MUI Glass Pixel** را به‌عنوان Home app انتخاب کنید.
